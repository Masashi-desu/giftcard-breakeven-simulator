# 金券換金 損益分岐点シミュレーター（インフレ考慮）

金券を使った場合の価値（額面 `F`）と、換金して運用した場合の将来価値（売却金額 `S` を元本）を比較し、インフレを考慮した実質ベースで損益分岐点を可視化する静的Webアプリです。

## 公開URL（GitHub Pages）

- https://masashi-desu.github.io/giftcard-breakeven-simulator/

## できること

- 入力値の変更を `input` イベントで即時計算
- インフレ調整後の実質損益 `P(n)` を 0..N 年で線グラフ表示
- 損益分岐年数を「約x年（小数第2位）」と「切り上げ年」で表示
- 例外条件（`S >= F` / `r <= i` など）をUI上で明示

## 使い方

1. `額面 F（円）`: 金券をそのまま使ったときの現在価値
2. `売却金額 S（円）`: 換金して運用に回せる元本
3. `名目年利 r（%）`: 運用の名目リターン
4. `インフレ率 i（%）`: 物価上昇率
5. `グラフ表示年数上限 N（年）`: 表示期間（0〜100年）

入力を変えると、結果カードとグラフが即座に更新されます。

## 計算式

- 換金ロス（名目）: `L = F - S`
- 実質成長倍率: `g = (1 + r) / (1 + i)`
- n年後の名目運用額: `FV_nominal(n) = S * (1 + r)^n`
- n年後の実質購買力: `FV_real(n) = S * g^n`
- 実質損益（購買力差）: `P(n) = FV_real(n) - F`

損益分岐条件 `FV_real(n) >= F` から、`g > 1` かつ `S < F` のとき:

- `n = ln(F / S) / ln(g)`

## 例外仕様

- `S <= 0` または `F <= 0`: 入力エラー
- `S >= F`: 損益分岐は `0年`（売却時点で損失なし）
- `g <= 1`（`r <= i`）かつ `S < F`: `黒字化しない（∞）`
- `g > 1` かつ `S < F`: 上式で損益分岐年を算出
